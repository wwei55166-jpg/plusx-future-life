# PlusX — 未来生命 / Future Life

A bilingual film showcase featuring five freshly sampled 90-second category montages, an ambient preview reel, a narrative short, and film/creator credits.

- 未来生态 / Future Ecology
- 后人类 / Posthuman
- 未来物种 / Future Species
- 深时记忆 / Deep Time Memory
- 演化身体 / Evolutionary Body

Each category montage contains 20 excerpts curated around photorealistic, abstract and futuristic imagery. Film titles and creator credits remain visible; the category-specific music is preserved.

## Run locally

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. No build step or third-party dependencies are needed.

## GitHub Pages

In repository Settings → Pages, select Deploy from a branch, main, / (root). All assets use relative paths and support project Pages URLs.
